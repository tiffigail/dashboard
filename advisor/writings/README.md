# Writings

Drop your essays, books-in-progress, and long-form thinking here.

Suggested structure:
  boxes/          — the Boxes essay series
  jim-and-i/      — the co-authored book project
  this-is-a-cult/ — the framework doc
  prompts/        — writing prompts generated by the advisor

Markdown format works best for LLM analysis.
Each file should have a header with: title, date, project, and any thematic tags.

Example header:
---
title: "On Negentropy and the Kitchen Drawer"
date: 2026-05-03
project: boxes
tags: [negentropy, meaning-making, environment]
---
