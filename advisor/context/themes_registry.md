---

## How to use this registry

When tagging an entry, prefer existing themes over creating new ones — but creating new ones is fine when no existing theme fits. The advisor will surface the registry during the entry-confirmation step so Abi can see what's available without having to memorize it.

Themes are written in `lowercase_snake_case`. They live under one or more axes. Some themes naturally span axes (e.g., `cello_voice` is primarily mental but shows up in spiritual contexts) — list them under their primary axis with a cross-reference note.

## Notes for the consolidator (the advisor, quarterly)

When consolidating, ask:

1. Are there themes that have appeared >5 times that should be elevated to "first-class" themes (added to this registry permanently)?
2. Are there themes that appeared once and never again, that should be archived?
3. Are there near-duplicates that should be merged? (e.g., `food-forest` vs `food_forest` — always the underscore version wins)
4. Are there clusters of related themes that suggest a new parent theme should be created?
5. Has any theme outgrown its axis? (e.g., what started as a `mental` theme might now span all seven — note this rather than force it back into one bucket)

After Abi confirms changes, the advisor runs a sweep across past entries to update any that used now-deprecated or now-merged tags. The corpus stays consistent.
